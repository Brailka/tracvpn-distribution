# tracVPN distribution

Этот репозиторий хранит только список серверов и выпуски APK. Исходного кода приложения здесь нет.

## Изменение серверов

Отредактируйте `Tracservis/servis.txt`: одна полная VLESS-ссылка на строку. После сохранения GitHub Actions проверит файл и обновит `catalog.json`. Приложение увидит список при следующем запуске или ручной проверке обновлений.

## Выпуск приложения

1. Увеличьте `versionCode` и версию приложения.
2. Соберите APK тем же постоянным ключом подписи.
3. Создайте GitHub Release и прикрепите APK с именем `tracVPN-VERSION_CODE-VERSION_NAME.apk`, например `tracVPN-4-1.1.1.apk`.
4. После публикации Release GitHub Actions добавит прямую ссылку на APK в `catalog.json`. У пользователей появится плашка обновления.

Android попросит пользователя подтвердить установку скачанного APK. Ключ подписи нельзя терять или менять: без него новая версия не установится поверх старой.

## Видимость

Для прямой загрузки без входа в GitHub репозиторий должен быть публичным. Поэтому `servis.txt`, `catalog.json` и APK будут доступны посетителям репозитория. Приватный репозиторий потребовал бы GitHub-токен внутри APK, который можно извлечь, поэтому это не даёт надёжной защиты.
